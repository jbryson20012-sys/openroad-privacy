    DATA & LIMITATIONS

    What this map knows

    01

    Community index

    U.S. camera coordinates come from the hourly DeFlock data pipeline, derived from OpenStreetMap surveillance tags. Brand labels appear where contributors supplied them.

    02

    No completeness claim

    Private installations can be unreported, moved, removed, mistagged, or newly installed. Treat every exposure total as an estimate—not a guarantee.

    03

    How routing works

    Google returns up to several lawful route alternatives. OpenRoad counts reported points near each path and can select the route with the smallest count. It does not invent roads or bypass closures.

    04

    Local-first

    Your API key and reports stay in local browser storage. No plate numbers, trip history, or identity data are collected by this static app.
